# File Management commands

##What I Did

I made a new file called `notes.txt` using `touch`. I put some text
inside it. I used `cat` to see what was written inside the file.

I made a copy of the file using `cp`. I checked `ls -l` to see both
files were there. I renamed the copy using `mv`. I checked `ls -l`
again to see the new name. At the end, I deleted the file using `rm`
and checked it was really gone.
